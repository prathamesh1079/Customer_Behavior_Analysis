# 📊 Customer Shopping Behavior Analysis

An end-to-end **Data Analytics project** analyzing customer shopping patterns, purchasing behavior, product performance, subscriptions, and customer segments using **Python, SQL, and Power BI**.

## 🎯 Project Objective

The goal of this project is to transform raw customer transaction data into meaningful business insights that can help improve:

* Customer retention
* Product performance
* Subscription adoption
* Marketing strategies
* Revenue growth

## 🛠️ Tech Stack

* **Python** – Data cleaning & exploratory data analysis
* **Pandas / NumPy** – Data manipulation
* **SQL** – Business analysis
* **Power BI** – Interactive dashboard
* **Jupyter Notebook** – Python analysis

## 🔄 Project Workflow

```text
Raw Data
   ↓
Data Cleaning
   ↓
Exploratory Data Analysis
   ↓
Feature Engineering
   ↓
SQL Analysis
   ↓
Power BI Dashboard
   ↓
Business Insights
```

## 📌 Key Analysis

The project explores:

* Customer purchasing behavior
* Revenue by customer segments
* Product and category performance
* Subscription vs non-subscription customers
* Discount usage
* Age-group purchasing patterns
* Customer ratings
* Shipping preferences
* Purchase frequency

## 📊 Power BI Dashboard

The interactive dashboard provides:

* Revenue & purchase KPIs
* Customer segmentation
* Product performance
* Subscription analysis
* Category analysis
* Rating analysis
* Interactive slicers and filters
